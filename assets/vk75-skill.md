# SD 2.5 Prompt

## 目标

把创意、素材或参考视频整理成可直接复制、容易生成、时间连续的 SD 2.5 视频提示词。默认保持简洁，不为了显得专业而堆叠模块。

默认只交付提示词，不提交生成任务。用户明确要求操作生成平台时再执行。

## 必读资料

- 每次写提示词前读取 [references/formula.md](references/formula.md)。
- 动作、追逐、旅程、氛围、揭示、对白、电影分镜或用户指定运镜时，读取 [references/directing.md](references/directing.md)。
- 需要选择题材或参考完整成品时读取 [references/examples.md](references/examples.md)。
- 只有多素材、原片反推、一镜到底、延长、智能编辑或白模渲染时，才读取 [references/modes.md](references/modes.md) 对应章节。

## 核心公式

严格使用用户指定的五段式：

```text
提示词 = 主体 + 风格 + 时间线 + BGM + 限制
```

1. **主体**：谁或什么，在什么场景，完成什么事件；有参考素材时同时写明各素材的职责。
2. **风格**：时长、画幅、清晰度、写实或动画、光线、色彩、质感和镜头基调。
3. **时间线**：从 0 秒覆盖到结尾，按时间写可见动作、运镜和落点；每段末尾接一个「声音：」，装这一段的环境声、动作音效和台词时机。
4. **BGM**：只写音乐本体——类型、速度/BPM、核心乐器、情绪曲线、结尾方式。没有音乐就写「无 BGM」，这一段不许省；对白和关键音效不写在这里。
5. **限制**：只写当前任务最容易出错的 3—8 项。

每段时间线使用：

```text
【时间】起始状态 + 主体动作 + 镜头拍法 + 结束状态。 声音：环境声 + 动作音效 + 台词时机
```

不要用“精彩地、酷炫地、激烈地”代替实际动作。

## 工作流

### 1. 写主体

先在内部盘点人物或产品、场景、道具、光线、天气、用户指定运镜和参考素材职责，再写主角、场景与核心事件。重复出现的人物或产品写明“全片同一”。改编或反推任务不添加素材中没有的人物、道具或事件；明确要求原创时才补充必要环境细节。

有参考素材时逐项声明：

```text
@图1锁定人物脸、发型和服装；不参考背景。
@图2锁定产品外形与材质；不改变比例和结构。
@视频1只参考动作节奏与运镜；不复制人物、品牌和声音。
@音频1作为完整 BGM；从 0 秒开始并在结尾收束。
```

### 2. 写风格

把输出规格和视觉语言合并在一段。至少包含：时长、画幅、成片类型、光线或色彩、镜头节奏。

不要同时要求互相冲突的风格，例如“固定机位”与“持续高速环绕”、“自然纪录感”与“每秒强转场”。

### 3. 写时间线

- 15 秒通常写 4—6 段。
- 30 秒通常写 5—8 段。
- 时间从 0 开始，覆盖目标时长，不重叠、不留空。
- 每段只安排一个主要动作和一个主要运镜。
- 上一段的结束状态应能成为下一段的起始状态。
- 每段末尾接「声音：」，写这一段的环境声、动作音效与台词时机；同一句台词只在它发生的那一段出现一次。

普通镜头写清动作即可。打斗、追逐、抛接、液体喷射或多人换位时，再补：

```text
谁发起 + 从哪里出发 + 沿什么路径 + 作用于谁 + 最后落在哪里
```

涉及切镜时，让下一段继承上一段的人物位置、朝向、运动方向和可见状态。复杂场景按 [references/directing.md](references/directing.md) 选择原型并设计镜头，不为炫技牺牲空间可读性。

### 4. 写 BGM

这一段只装音乐本体：音乐类型、速度或 BPM、核心乐器、起伏和结尾方式。需要贴合画面时，把关键节拍对应到时间点。

对白和音效不写在这里。台词（说话人、语言、原文、情绪）与关键音效（脚步、纸响、门响、机械声）都写进【时间线】对应段末尾的「声音：」，并在那里标出发声时机。

没有音乐时明确写“无 BGM”，并说明这段时间靠哪些环境声撑住。不要省略这一段——检查脚本要求【BGM】存在。

### 5. 写限制

限制控制在 3—8 项，优先处理：

- 人物变脸、换装、复制或人数变化。
- 产品变形、包装漂移、材质错误。
- 动作穿模、受力方向错误、无来源攻击。
- 乱码、额外字幕、商标和水印。
- 额外对白、音乐盖住人声或节拍错位。

先修正文中的矛盾，再写限制；不要用几十个否定词掩盖含糊的动作。

## 模式规则

- **从零生成**：根据用户创意完成五段式。
- **多模态参考**：把素材职责放进“主体”，不要另建复杂表格。
- **原片反推**：按真实切点还原，不添加原片没有的动作、转场、对白或场景。
- **创意延伸**：保留参考片核心设定，新增内容明确标注为延伸。
- **视频延长**：只写原片末帧、新增时段和最终落点。
- **智能编辑**：写清修改对象、生效时段与必须保持不变的内容。
- **一镜到底**：时间段代表动作阶段，不代表切镜；摄影机路线必须连续。
- **导演分镜**：先判断动作、旅程/氛围/揭示或对白原型，再把镜头、调度和空间连续性写回五段式，不另建 JSON 或“镜头表”一级模块。

## 平台操作规则

提示词写完之后，平台上还有几步最容易出错，按这个顺序做：

- **上传顺序就是提示词里的编号**。提示词写 `@图片1`，平台第 1 格就必须放它对应的那张。上传前照着缩略图逐格核对一遍——**放错一格，模型就会张冠李戴**，把 A 的脸装到 B 身上。
- **每条提示词只挂一条视频**，所以它在平台里永远叫 `@视频1`。传哪个文件必须写清楚，不要指望平台记住上一条传的是哪个。
- **视频槽只传真预演母版或成片**。抽帧图、多格对照图、带标注的对比图**一律不上传**——模型会把它们当成画面内容抄进成片。
- **素材逐项声明职责**，写成 `@图片N：参考……；不参考……`。只写“参考”不写“不参考”，模型会连影棚灰底、平光、拼图版式一起带进画面。
- **【风格】里写的清晰度必须和平台底栏的设置一致**。文本写 4K、平台设 720p 就是自相矛盾，生成前先对齐。
- **交付时附一段「已知局限（生成前先看）」**，把这条提示词最容易崩的地方先讲明。

## 检查与交付

运行：

```bash
python3 scripts/check_prompt.py <提示词文件> --duration 15
```

无品牌任务增加：

```bash
python3 scripts/check_prompt.py <提示词文件> --duration 15 --unbranded
```

交付时：

1. 完整提示词放在一个 `text` 代码块中。
2. 五个标题使用“主体、风格、时间线、BGM、限制”。
3. 除非用户要求，不额外输出长篇分析。

## 最低质量线

- 前 1—2 秒出现主体、产品、冲突或强视觉动作。
- 人物、产品和场景前后一致。
- 时间轴覆盖完整时长。
- 每段动作能在分配时间内完成。
- 用户指定的角度、焦段或运镜已落实；切镜后位置、朝向和运动方向可追踪。
- BGM 与关键动作有节拍对应，结尾自然收束。
- 每段时间线都带「声音：」且与画面同点；无音乐时【BGM】段写明「无 BGM」。
- 结尾有明确动作落点或稳定英雄画面。

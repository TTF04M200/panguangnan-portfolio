# Blender 材质桥接 · 使用说明

打通 RizomUV、Substance Painter 与 Coat 的 Blender 材质工作流插件。

## 安装
1. Blender 菜单「编辑 / 偏好设置 / 插件」→ 安装；
2. 选择本插件 zip，启用后在侧边栏出现「材质桥接」标签。

## 核心功能
- Material Builder：可视化组装 Principled BSDF 节点；
- RizomUV 自动展开：一键 UV 布局与堆叠检测；
- Substance Painter 互导：贴图路径自动映射；
- 偏好管理：多项目材质预设一键切换。

## 快捷键
- `N` 键 → 侧边栏 → 材质桥接面板。

## 支持
- Blender 3.6+（Win / macOS）

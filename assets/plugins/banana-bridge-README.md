# Banana Bridge · 使用说明

面向 Photoshop 的 AI 创作桥接面板。

## 安装
1. 将 `BananaBridge` 文件夹复制到 Photoshop 插件目录
   `Plug-ins/Panel` 下；
2. 重启 Photoshop，在「窗口 / 扩展」中打开 Banana Bridge。

## 核心功能
- 3D 镜头控制：推拉摇移与构图参考实时预览；
- 200+ 面部精修预设：皮肤、五官、光影一键套用；
- 场景与音效素材：拖入即用，内置分类管理。

## 快捷键
- `Ctrl/Cmd + Shift + B`：展开/收起面板。

## 支持
- Photoshop 2021+（Win / macOS）
